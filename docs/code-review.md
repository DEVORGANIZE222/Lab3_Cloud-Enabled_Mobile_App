# AI Code Review — PRM393 Lab 3

> **Đang chờ review thật.** Bản trước của file này ghi 6 phát hiện "Gemini Code Assist", nhưng nhánh `feat/lab3-firebase-fixes` chưa từng có pull request nào, nên Gemini Code Assist chưa thể review nó. Các phát hiện đó thực chất lấy từ [`firebase-audit-lab3.md`](firebase-audit-lab3.md) và đã bị gỡ bỏ.

## Quy trình sẽ thực hiện

1. Cài **Gemini Code Assist for GitHub** (miễn phí, hỗ trợ repo private) cho repo `DEVORGANIZE222/Lab3_Cloud-Enabled_Mobile_App`.
2. Mở pull request `feat/lab3-firebase-fixes` → `main`; Gemini Code Assist tự động để lại review.
3. Ghi lại ở đây từng comment của Gemini (≥ 5 phát hiện, ≥ 2 nhóm) kèm file/dòng và link comment.
4. Với mỗi phát hiện: **Chấp nhận / Điều chỉnh / Bác bỏ**, kèm lý do kỹ thuật.
5. Sửa ≥ 3 phát hiện được chấp nhận, mỗi bản sửa một commit trên PR, ghi hash commit vào bảng.
